# Site institucional — Pedro & Luzia Advogados (projeto de demonstração)

Site fictício desenvolvido como peça de portfólio para o nicho de **serviços institucionais**
(escritórios de advocacia, clínicas, consultórios e outros prestadores de serviço que precisam
de transmitir confiança e credibilidade online).

🔗 **Demo ao vivo:** _[(adicionar link do GitHub Pages depois do deploy)](https://teca09.github.io/site-servicos-institucionais/)_

## Sobre o projeto

"Pedro & Luzia Advogados" é um escritório de advocacia fictício em Luanda. O objetivo do site
é transmitir seriedade e confiança, e converter visitantes em consultas marcadas via WhatsApp.

## Stack

- HTML5 semântico
- CSS3 puro (sem frameworks) — variáveis CSS para o sistema de design
- JavaScript vanilla (menu mobile)
- Tipografia: [Fraunces](https://fonts.google.com/specimen/Fraunces) + [Inter](https://fonts.google.com/specimen/Inter)

## Estrutura


## Nota sobre as imagens

As imagens usadas são placeholders gerados por serviços gratuitos ([picsum.photos](https://picsum.photos)
e [pravatar.cc](https://pravatar.cc)), próprios para projetos de demonstração. Num projeto real para
cliente, seriam substituídas por fotografias reais do escritório e da equipa.
